# Carte eclaire
 Application R-shiny pour pratiquer l'identification d'espèces sur des photos de capture. 

Vous pouvez (essayer un démo seulement sur le réseau interne MPO):  https://shiny.ent.dfo-mpo.ca/cards

# Installation
Ce dépot ne contient pas de photos, voir `admin.R` pour faire un deck a partir d'une mission ANDES.

# Remerciments


Cette application utilise les cartes du domaine publique obtenus sur http://www.naturalearthdata.com/
